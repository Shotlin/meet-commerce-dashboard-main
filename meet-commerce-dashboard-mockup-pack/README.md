# Meet Commerce Dashboard Mockup Pack

This is a production-direction asset pack for the Meet Commerce admin and warehouse dashboard. It is based on the supplied backend blueprint and remediation specification, plus the structural depth of the Bakaloo dashboard reference.

## Contents

- `01-banner-assets/` - four editable-use campaign backgrounds with copy-safe negative space.
- `02-dashboard-mockups/` - fourteen high-fidelity desktop mockups. The primary operations screens are full-size; the related boards each contain four route concepts.
- `DESIGN-SYSTEM.md` - visual tokens, typography, data-visualisation language and accessibility rules.
- `PAGE-COVERAGE.md` - screen-to-capability coverage, including the cutting-evidence video workflow.
- `COMPLETENESS-AUDIT.md` - the gap audit and the explicit dashboard-only scope boundary.

## How to use the images

Treat the mockups as visual direction, not as pixel-for-pixel production source. Preserve the shared left navigation, top context bar, 8px spacing rhythm, chart colour semantics, role-gated actions and compact information hierarchy. Use the banner images with HTML text over their intentionally clear left sides; do not bake promotional copy into the supplied artwork.

## Generation record

Generated with the built-in Image Generation workflow. Prompts were structured as `ads-marketing` for the banner assets and `ui-mockup` for the dashboard images, specifying a premium, pink-forward Meet Commerce system, desktop Figma-quality composition, data visualisation and constrained, readable UI. No third-party visual assets or logos were used.
